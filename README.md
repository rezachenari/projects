# پارس ویترین — وب‌سایت طراحی و ساخت ویترین و مانکن طلا

وب‌سایت فارسی (RTL) و سینمایی برای مجموعه‌ای تخصصی در طراحی، ساخت و اجرای ویترین طلافروشی،
مانکن و استند نمایش طلا و دکوراسیون گالری‌های طلا و جواهر.

- **فرانت‌اند:** React 18 + Vite (بدون فریم‌ورک CSS؛ سیستم طراحی اختصاصی در `frontend/src/styles`)
- **بک‌اند:** Express + PostgreSQL
- **اجرا:** Docker Compose (`docker-compose.base44.yml`)

---

## اجرا

```bash
docker compose -f docker-compose.base44.yml up -d --build
```

- سایت: `http://localhost:3000`
- API: `http://localhost:8000` (و از داخل سایت روی مسیر `/api` هم در دسترس است)
- اولین اجرا، اسکیمای دیتابیس را می‌سازد و محتوای اولیه را وارد می‌کند (سرویس `migrate`).

پس از تغییر محتوا در `backend/src/seed-data.js`:

```bash
docker compose -f docker-compose.base44.yml run --rm migrate
```

## ساختار

```
frontend/
  public/images/        تصاویر بهینه‌شده (WebP، محلی)
  public/fonts/         وزیرمتن (SIL OFL) — فونت در حال استفاده
  src/components/       هدر، فوتر، کارت‌ها، فرم‌ها، سکشن‌های صفحه اصلی
  src/pages/            خانه، محصولات، دسته‌بندی، جزئیات محصول، خدمات، پروژه‌ها،
                        درباره ما، مقالات، تماس، درخواست مشاوره، ۴۰۴
  src/styles/           توکن‌های طراحی، لایه پایه، چیدمان، کامپوننت‌ها، سکشن‌ها
backend/
  src/schema.sql        جداول: site_settings, categories, products, projects, articles, leads
  src/seed-data.js      تمام محتوای قابل ویرایش سایت
  src/seed.js           اسکیمای idempotent + همگام‌سازی محتوا
  src/server.js         API عمومی
```

## فرم‌ها و داده‌ها

فرم درخواست مشاوره/استعلام قیمت به یک API واقعی متصل است و درخواست‌ها در جدول `leads`
دیتابیس ذخیره می‌شوند (اعتبارسنجی سمت سرور، نرمال‌سازی ارقام فارسی، محدودیت نرخ ارسال).
پس از ثبت موفق، شماره پیگیری نمایش داده می‌شود؛ هیچ ادعای ارسال پیامک یا ایمیل وجود ندارد،
چون سرویس پیامکی متصل نشده است.

مشاهده درخواست‌های ثبت‌شده:

```bash
docker compose -f docker-compose.base44.yml exec db \
  psql -U parsvitrin -d parsvitrin -c "SELECT id, full_name, phone, request_type, city, created_at FROM leads ORDER BY created_at DESC;"
```

> پیش از انتشار، دسترسی به این جدول را محدود کنید (در حال حاضر پنل مدیریت یا احراز هویت
> برای مشاهده درخواست‌ها وجود ندارد و دسترسی از طریق دیتابیس انجام می‌شود).

## تصاویر

تصاویر از عکس‌های آزاد Unsplash (مجوز Unsplash، قابل استفاده تجاری) انتخاب، برش و به
فرمت WebP تبدیل شده‌اند و به‌صورت محلی در `frontend/public/images` سرو می‌شوند؛ هیچ
تصویری از منبع خارجی به‌صورت hotlink بارگذاری نمی‌شود. پیش از استفاده تجاری نهایی،
توصیه می‌شود عکس‌های اختصاصی پروژه‌های واقعی جایگزین شوند.

## فونت

فونت اصلی برند **IRANYekan** است. فایل‌های این فونت به‌دلیل مجوز اختصاصی در مخزن قرار
نگرفته‌اند و ادعای نصب آن وجود ندارد. در حال حاضر **Vazirmatn** (مجوز SIL OFL) به‌صورت
محلی سرو می‌شود و در `--font-fa` بعد از IRANYekan قرار دارد.

برای فعال‌سازی IRANYekan:

1. فایل‌های مجاز را در `frontend/public/fonts/iranyekan/` قرار دهید.
2. بلوک `@font-face` را در `frontend/src/styles/iranyekan.css` از حالت کامنت خارج کنید.
3. آن فایل را در `frontend/src/main.jsx` ایمپورت کنید.

## موارد نیازمند جایگزینی پیش از انتشار

- شماره تماس، ایمیل، نشانی و شبکه‌های اجتماعی (جدول `site_settings`) — مقادیر فعلی نمونه‌اند
  و در رابط کاربری نیز با یادداشت مشخص شده‌اند.
- قیمت محصولات: عمداً خالی است و «استعلام قیمت» نمایش داده می‌شود.
- نظرات مشتریان: نمونه نمایشی با برچسب مشخص؛ نظر واقعی ثبت نشده است.
- نام پروژه‌ها: به‌عنوان «نمونه طراحی» معرفی شده‌اند.

## توسعه سئو

عنوان و توضیحات متا برای هر صفحه به‌صورت داینامیک تنظیم می‌شود، ساختار H1/H2/H3 رعایت شده،
data ساختاریافته (Product، Article، CreativeWork) در صفحات جزئیات تزریق می‌شود و مسیرها
خوانا و کوتاه هستند.

## دسترس‌پذیری

RTL کامل با ویژگی‌های منطقی CSS، برچسب مرئی برای همه فیلدها، وضعیت focus-visible،
`prefers-reduced-motion`، لینک پرش به محتوا، و منوی موبایل با مدیریت فوکوس و بستن با Esc.
